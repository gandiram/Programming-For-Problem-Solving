The one idea behind the whole unit

An array turns many variables into one variable plus a number. That number is what makes loops useful: for (i = 0; i < n; i++) can visit every element, so the same three lines work for 10 marks or 10,000. Every algorithm in this unit is a loop over subscripts.

Part A · Array Basics

Storing Many Values Under One Name

An array is a collection of elements of the same type, stored in consecutive memory, reached by a name and an index. Part A covers declaring them, indexing them safely, and passing them to functions — where they behave unlike anything in Unit III.

Declaring and Referencing Arrays

An array declaration reserves a block of consecutive memory cells, all of the same type, and gives the whole block one name.

1.1

The declaration

type name[size]; int marks[5]; /* 5 int cells, indexes 0 to 4 */ float price[100]; /* 100 float cells */

The size must be a constant known when the program is compiled — a literal, or a #define, or a const. It cannot be a variable read from the user, because the compiler must know how much memory to reserve.

1.2

Initialising an array

Written asResult
int a[5] = {1, 2, 3, 4, 5};All five elements set
int a[5] = {1, 2};a[0]=1, a[1]=2, and the rest are set to 0
int a[5] = {0};A common idiom: every element becomes 0
int a[] = {7, 8, 9};The compiler counts them — size becomes 3
int a[5];No initialiser: all five hold garbage
Three things you cannot do

1. int a[5]; a = {1,2,3,4,5}; — an array can only be initialised where it is declared. Afterwards you must assign element by element.

2. b = a; — you cannot copy one array into another with =. Use a loop.

3. if (a == b) — you cannot compare two arrays with ==. Compare element by element in a loop.

Array Subscripts

  
The subscript (or index) selects one element. It may be any integer expression, which is exactly what lets a loop walk through the whole array.


  

    
2.1
Any integer expression will do

    

    

      
Written asSelects

      
        
a[0]The first element

        
a[i]The element at whatever i currently holds

        
a[i+1]The next one — used by every sorting algorithm

        
a[n-1]The last element of an n-element array

        
a[2*i]Every second element

      
    

    

    

      
walk.cthe standard loop

      
1for (i = 0; i < n; i++)        /* 0 to n-1: the whole array, exactly once */2    printf("%d ", a[i]);

    

    

      Learn this loop shape once
      
i = 0, condition i < n, update i++. Note it is < n, not <= n. Writing <= n reads one element past the end — the single most common array bug there is.

    

  


  

    
2.2
C does not check the bounds

    

      Out of range is not an error — it is worse
      
With int a[5]; the expression a[7] compiles happily and runs. It simply reads whatever memory happens to sit two cells past the end of the array. You may get garbage, you may corrupt another variable, or the program may crash — and it may behave differently every run.

      
Unlike Python or Java, C performs no bounds checking at all. Guarding the index is entirely your job. The runner on this page does check, and tells you which index went out of range — a real compiler will not.

    

    

      
Off by one

        
for (i = 1; i <= 5; i++)
    sum += a[i];

        
Misses a[0] and reads a[5], which does not exist. Both ends are wrong.

      
Correct

        
for (i = 0; i < 5; i++)
    sum += a[i];

        
Visits a[0] to a[4] — every element, exactly once.

    

    

      A useful idiom
      
int n = sizeof(a) / sizeof(a[0]); computes the number of elements: the total bytes divided by the bytes in one element. It keeps working when you change the size of the array. It only works where the array was declared — inside a function that received the array, sizeof no longer knows the size, which is why the length is always passed as a separate parameter.

    

  







  
TOPIC 03Hanly & Koffman §8.4

  
Using Array Elements as Function Arguments

  
A single element such as a[2] is just an ordinary value of its type. Passing it to a function is call by value, exactly as in Unit III — nothing new to learn.


  

    
3.1
An element behaves like any variable

    

      
element.cone element, by value

      
1int square(int n) { return n * n; }23int a[5] = {1, 2, 3, 4, 5};45printf("%d", square(a[2]));   /* passes the VALUE 3 -> prints 9 */6printf("%d", a[2]);           /* a[2] is still 3 */

    

    

      The distinction that matters in this unit
      
f(a[i]) passes one value, copied — the function cannot change the array.

      f(a) passes the whole array, shared — the function can change it. That is Topic 04, and it is the one place where C stops copying.

    

  







  
TOPIC 04Hanly & Koffman §8.5

  
Array Arguments

  
When you pass a whole array, C does not copy it. The function receives the address of the first element, so it works on the caller's own array — and any change it makes is permanent.


  

    
4.1
How an array parameter is written

    
int total(int a[], int n)      /* the size is left empty and passed separately */
{
    ...
}

total(marks, 5);                /* the call: just the name, no brackets */

      Why the length must be passed too
      
Inside the function, a is only an address — the size information is gone, so sizeof(a) no longer gives the array size. That is why every array function in C takes the number of elements as a second parameter. Forgetting it is how programs read past the end.

Linear Search

  
Linear search — also called sequential search — looks at each element in turn until it finds the target or runs out of array. It is the only search that works on unsorted data.


  

    
5.1
The algorithm

    

      
Linear search

      
    
        
  1. Start
    2. 
        
  2. Set pos = −1 (meaning "not found yet")
    3. 
        
  3. For i from 0 to n−1:
          
    • if a[i] equals the key, set pos = i and break out of the loop
    
        
    4. 
        
  4. If pos ≥ 0 display the position, otherwise display "not found"
    5. 
        
  5. Stop
    6. 
      

    

    

      
linear.cworks on any array

      
1int linearSearch(int a[], int n, int key)2{3    int i;4    for (i = 0; i < n; i++)5        if (a[i] == key) return i;    /* found -- return the index */6    return -1;                        /* not found */7}

    

    

      Why −1 means "not found"
      
Every valid index is 0 or more, so −1 cannot be mistaken for a real position. Returning 0 for failure would be a bug, because 0 is the first element.

    

  


  

    
5.2
How much work it does

    

    

      
CaseComparisonsWhen

      
        
Best1The key is the first element

        
Averageabout n / 2The key is somewhere in the middle

        
WorstnThe key is last, or absent altogether

      
    

    

    
For 1000 elements, a failed linear search costs 1000 comparisons. Binary search does the same job in about 10 — but demands something in return.

  







  
TOPIC 06Hanly & Koffman §8.6

  
Binary Search

  
Binary search repeatedly halves the region being searched. It is dramatically faster than linear search, but it has one absolute requirement: the array must already be sorted.


  

    
6.1
The algorithm

    

      
Binary search

      
    
        
  1. Start
    2. 
        
  2. Set low = 0 and high = n−1
    3. 
        
  3. While low ≤ high:
          
      
            
    • mid = (low + high) / 2
      • 
            
    • if a[mid] equals the key → found at mid, stop
      • 
            
    • if a[mid] < key → the key must be to the right, so low = mid + 1
      • 
            
    • otherwise → the key must be to the left, so high = mid − 1
      • 
          
    
        
    4. 
        
  4. If the loop ends, the key is not present
    5. 
        
  5. Stop
    6. 
      

    

    

      
    

  


  

    
6.2
Linear against binary

    

    

      
PointLinear searchBinary search

      
        
Array must be sortedNoYes

        
MethodCheck every element in turnHalve the region each pass

        
Worst casen comparisonsabout log₂n comparisons

        
For n = 1000100010

        
For n = 1,000,0001,000,00020

        
Best forSmall or unsorted dataLarge sorted data searched often

      
    

    

    

      Two traps
      
The loop condition is low <= high, not <. With < the search fails whenever the key is the last element still under consideration.

      
mid must be recomputed every pass. Calculating it once before the loop gives an infinite loop, because the region shrinks but mid never moves.

Bubble Sort

  
Bubble sort repeatedly compares neighbouring pairs and swaps them if they are the wrong way round. After each pass the largest remaining value has "bubbled" to the end.


  

    
7.1
The algorithm

    

      
Bubble sort

      
    
        
  1. Start
    2. 
        
  2. For i from 0 to n−2:  (n−1 passes)
          
      
            
    • for j from 0 to n−2−i:  (the tail is already sorted)
      • 
            
    • if a[j] > a[j+1] then swap them
      • 
          
    
        
    3. 
        
  3. Stop
    4. 
      

    

    

      
bubble.ccompares neighbours

      
1for (i = 0; i < n - 1; i++)2    for (j = 0; j < n - 1 - i; j++)     /* -i: the end is already done */3        if (a[j] > a[j + 1]) {4            t = a[j];  a[j] = a[j + 1];  a[j + 1] = t;5        }

    

    

      Why the inner loop shrinks
      
After pass 1 the largest value is certainly at the end; after pass 2 the two largest are in place, and so on. Comparing them again would be wasted work, so the inner limit is n-1-i. Leaving out the -i still sorts correctly, just more slowly.

Selection Sort and Insertion Sort

  
Two more sorts, each with a different idea. Selection sort finds the smallest and puts it in place. Insertion sort takes the next value and slides it back into the sorted part.


  

    
8.1
Selection sort

    

      
Selection sort

      
    
        
  1. Start
    2. 
        
  2. For i from 0 to n−2:
          
      
            
    • assume the minimum is at position i, so min = i
      • 
            
    • for j from i+1 to n−1: if a[j] < a[min] then min = j
      • 
            
    • swap a[i] and a[min]
      • 
          
    
        
    3. 
        
  3. Stop
    4. 
      

    

    
The distinguishing feature: at most one swap per pass, made only after the whole remaining region has been scanned. That makes it the best of the three when swapping is expensive.

  


  

    
8.2
Insertion sort

    

      
Insertion sort

      
    
        
  1. Start
    2. 
        
  2. For i from 1 to n−1:
          
      
            
    • key = a[i]  (the value to place)
      • 
            
    • j = i − 1
      • 
            
    • while j ≥ 0 and a[j] > key: move a[j] one place right, then j = j − 1
      • 
            
    • a[j+1] = key
      • 
          
    
        
    3. 
        
  3. Stop
    4. 
      

    

    

      The card-player's sort
      
This is exactly how most people sort a hand of cards: keep the left part in order, pick up the next card, and slide it back until it fits. It is the fastest of the three on data that is already nearly sorted, because the inner while loop then barely runs.

    

  


  

    
8.3
The three sorts compared

    

    

      
PointBubbleSelectionInsertion

      
        
IdeaSwap neighbours that are out of orderFind the smallest, put it in placeInsert the next value into the sorted part

        
Comparisons (worst)n²/2n²/2n²/2

        
Swaps / moves (worst)Many — up to n²/2At most n−1Many

        
Best casen, if you add a "swapped" flagn² — it always scans fullyn, when already sorted

        
Nearly sorted dataGood with the flagNo benefit at allExcellent

        
Best used whenTeaching; very small arraysSwapping is costlyData is small or nearly ordered

      
    

    

    

      All three are O(n²), and that matters
      
Doubling the array roughly quadruples the work. For 10 elements any of them is instant; for a million, all three are hopeless — that is what quicksort and mergesort are for, in a later course. Learn these three for the ideas, not for production use.

Two-dimensional Arrays

  
A 2D array is declared with two sizes and indexed with two subscripts: the first selects the row, the second the column.


  

    
9.1
Declaration and layout

    
int m[3][4];        /* 3 rows, 4 columns, 12 elements in all */

m[0][0]  ... first row, first column
m[2][3]  ... last row, last column

    

      
    

  


  

    
9.2
Initialising and traversing

    

      
grid.cnested loops

      
1int m[2][3] = {{1, 2, 3},2                {4, 5, 6}};   /* braces per row make it readable */34for (i = 0; i < 2; i++) {          /* outer loop -> rows    */5    for (j = 0; j < 3; j++)        /* inner loop -> columns */6        printf("%d ", m[i][j]);7    printf("\n");              /* end of the row */8}

    

    

      The pattern for every 2D problem
      
Outer loop over rows, inner loop over columns, and the newline printed by the outer loop. Put the newline in the inner loop and every value lands on its own line. That one line placement is the difference between a grid and a column.

    

    

      m[i,j] is not how you index in C
      
m[1,2] compiles, but the comma operator throws away the 1 and the expression becomes m[2] — an entire row, not an element. C always needs separate brackets: m[1][2].

Matrix Addition

  
Two matrices are added element by element. It is the simplest 2D algorithm: one pair of nested loops, one addition.


  

    
10.1
The rule and the algorithm

    

      The requirement
      
Both matrices must have exactly the same order — the same number of rows and the same number of columns. A 2×3 cannot be added to a 3×2. The result has that same order.

      
C[i][j] = A[i][j] + B[i][j]

    

    

      
Matrix addition

      
    
        
  1. Start
    2. 
        
  2. Read the two matrices A and B, each of order r × c
    3. 
        
  3. For i from 0 to r−1:
          
    • for j from 0 to c−1: C[i][j] = A[i][j] + B[i][j]
    
        
    4. 
        
  4. Display C row by row

  5. Stop

TOPIC 11Hanly & Koffman §8.9

  
Matrix Multiplication

  
Multiplication is not element by element. Each result cell is a row of A combined with a column of B, which is why it needs three nested loops.


  

    
11.1
The rule

    

      The requirement, and the shape of the answer
      
The columns of A must equal the rows of B. An m×n matrix times an n×p matrix gives an m×p result. The two n values must match; they are the dimension that disappears.

      
C[i][j] = Σ over k of A[i][k] × B[k][j]

    

    

      
Matrix multiplication

      
    
        
  1. Start
    2. 
        
  2. Read A (m×n) and B (n×p)
    3. 
        
  3. For i from 0 to m−1:
          
      
            
    • for j from 0 to p−1:
      • 
            
    •   set C[i][j] = 0
      • 
            
    •   for k from 0 to n−1: C[i][j] = C[i][j] + A[i][k] × B[k][j]
      • 
          
    
        
    4. 
        
  4. Display C
    5. 
        
  5. Stop
    6. 
      

    

    

      
    

    

      Three mistakes to avoid
      
1. Forgetting c[i][j] = 0; before the k loop.

      
2. Writing B[j][k] instead of B[k][j] — the k must run down B's rows.

      
3. Not checking that A's columns equal B's rows before starting.

Declaring Multidimensional Arrays

  
C allows any number of dimensions. Three-dimensional arrays appear often enough — a stack of tables, a set of grids, marks for several subjects across several terms.


  

    
12.1
Beyond two dimensions

    

    

      
DeclarationMeaningElementsLoops needed

      
        
int a[6];A list of 661

        
int m[3][4];3 rows × 4 columns122

        
int c[2][3][4];2 tables of 3 × 4243

        
int s[5][3][4];5 students × 3 terms × 4 subjects603

      
    

    

    
The total number of elements is the product of all the sizes, and the memory used is that product times the size of one element. int s[5][3][4] occupies 60 × 4 = 240 bytes.

    

      Passing multidimensional arrays to functions
      
Only the first dimension may be left empty. Every later size must be given, because the compiler needs them to compute the offset i × cols + j:

      
void show(int m[][4], int rows)   ✓ correct

      void show(int m[][], int rows)   ✗ error

    

    

      Memory grows very fast
      
Each extra dimension multiplies the size. int a[100][100][100] is a million ints — about 4 MB, which will usually overflow the stack if declared inside a function. Beyond two dimensions, think about the total before you declare it.

One line per topic

    

      
01Declaring arraysA fixed number of same-type elements in consecutive memory. The size must be a compile-time constant; a partial initialiser zero-fills the rest.

      
02SubscriptsAny integer expression selects an element. Valid indexes are 0 to n−1, and C performs no bounds checking whatsoever.

      
03Elements as argumentsa[i] is an ordinary value, so it is passed by value and the function cannot change the array.

      
04Array argumentsThe array name passes the address of the first element, so the function shares the caller's array and its changes are permanent. The length must be passed too.

      
05Linear searchCheck each element in turn. Works on any array; n comparisons in the worst case.

      
06Binary searchHalve the region each pass. Needs a sorted array; about log₂n comparisons — 20 for a million elements.

      
07Bubble sortSwap neighbours that are out of order; the largest bubbles to the end each pass. O(n²), with many swaps.

      
08Selection & insertionSelection finds the minimum and makes at most one swap per pass. Insertion slides each value back into the sorted part and is excellent on nearly sorted data.

      
092D arraysTwo subscripts: row then column. Stored in row-major order, so m[i][j] sits at offset i × columns + j. Traversed with nested loops.

      
10Matrix additionElement by element, so both matrices must have the same order. Two nested loops.

      
11Matrix multiplicationRow of A against column of B: three nested loops, and C[i][j] must be reset to 0 before the k loop. A's columns must equal B's rows.

      
12Multidimensional arraysAny number of dimensions; each one adds a loop. Only the first size may be omitted in a function parameter.
