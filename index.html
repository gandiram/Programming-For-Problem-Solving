Programming for Problem Solving

Unit-wise study notes, written in plain language and traced through real cases. Pick a unit to begin.

Units

Unit I

Logic Building, C Fundamentals, Operators & Expressions

Twenty topics plus a worked-examples laboratory: 12 mathematical problems, 10 operator examples and 10 precedence problems — each with algorithm, pseudocode, instruction-by-instruction tracing with memory addresses, and a C code editor. Includes Dev-C++ and Ubuntu execution side by side.

Control Statements: Selection, Loops and Jumps

Twelve topics plus 26 worked examples: if, if-else, nested if and the else-if ladder, switch, the while, for and do-while loops, nested loops, and break, continue and goto — with iteration-by-iteration tracing and a live C runner.

Functions and Program Structure

Twelve topics plus 74 worked examples: user-defined functions, prototypes, inter-function communication and call by value, scope and lifetime, the four storage classes, type qualifiers, the C preprocessor and recursion — with call-stack tracing and a live C runner.

Open Unit III → Unit IV

Arrays, Searching and Sorting

Twelve topics plus 74 worked examples: declaring and referencing arrays, subscripts, array arguments, linear and binary search, bubble, selection and insertion sort, two-dimensional arrays and matrix operations — with pass-by-pass tracing and a live C runner.

Open Unit IV → Unit V

Pointers and Strings

Twelve topics plus 74 worked examples: pointers and addresses, pointer types, function arguments, pointers and arrays, address arithmetic, arrays of pointers, pointers to pointers, dynamic memory allocation and C strings — with address-level tracing and a live C runner.
